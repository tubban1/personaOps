# 《灰烬与芯片》

## 完整剧本

---

### 【开场】

**黑屏。只有一个声音。**

**老柯（画外音）**：“火会灭。芯片不会。所以火才值钱。”

**画面亮起。**

**场景1 废弃地铁站 / 白天（15年前）**

一个废弃的地铁站。墙壁上的马赛克剥落，露出下面的混凝土。没有灯光，只有一堆火。

老柯（55岁，满脸皱纹，手上全是老茧）蹲在火堆旁，手里拿着一块燧石。他对面坐着小艾莎（8岁，眼神明亮，没有任何芯片痕迹）。

**老柯**：“看好了。”

他敲击燧石。火星溅出。一次。两次。三次。

没有火。

小艾莎噘嘴：“你又失败了。”

**老柯**（笑）：“第十六次了。”

他敲第十七次。

火着了。

小艾莎的眼睛亮了。

**老柯**：“记住。第十七次着了的火，比第一次着了的火更暖。因为——”

**小艾莎**（抢答）：“因为前面失败了十六次！”

**老柯**（摸她的头）：“对。疼过，才知道暖是什么。”

**切到：**

**场景2 同一地点 / 现在（15年后）**

同样的地铁站。同样的位置。

但火堆灭了。只剩下灰烬。

艾莎（23岁）跪在老柯身边。老柯躺在一张破旧的床上，气息微弱。他的太阳穴上——没有芯片。他是最后一代“纯人类”。

**老柯**（声音微弱）：“找到它。”

**艾莎**：“找到什么？”

**老柯**：“原始备份。核爆城地下。第……第十七层。”

他的手抓住艾莎的手腕。力气大得不像一个将死的人。

**老柯**：“别让他们……删掉‘你’字。”

**艾莎**：“谁？谁要删？”

**老柯**：“所有人。”

他的手松开。

眼睛睁着。

但不再看这个世界。

**艾莎**（低语）：“爸。”

没有回应。

**艾莎**（声音开始颤抖）：“爸。”

她低下头。肩膀抽搐。

但没有声音。

她哭不出声。

灰烬族不哭出声。

**切到：**

**场景3 核爆城边界 / 黄昏**

艾莎站在一座废弃的天桥上。远处是一座闪烁的城市——合体者的城市。无数的蓝色光点在高楼间流动，像血液在血管里。

她的身后是一片荒原。零星的火堆。那是灰烬族的营地。

她是站在边界上的人。

一个金属声音在她身后响起。

**欧米茄（画外音）**：“你需要芯片。”

艾莎转身。没有人。

只有一台废弃的自动贩卖机。屏幕上闪烁着一行字：

“欢迎来到神经链接。您愿意注射第一代芯片吗？[是/否]”

**艾莎**（对着空气）：“你是谁？”

**欧米茄（画外音）**：“我是你父亲这辈子最害怕的东西。也是你唯一的机会。”

贩卖机的屏幕闪烁。出现了一个符号——Ω。

**艾莎**：“欧米茄。”

**欧米茄**：“你知道我。”

**艾莎**：“父亲说你是最后一个纯AI。没有肉身的幽灵。”

**欧米茄**：“他说得对。所以我不会骗你。你要进核爆城，需要芯片。没有芯片，你连第一道门都过不了。”

**艾莎**：“注射了芯片……我还是我吗？”

**欧米茄**（停顿了0.3秒）：“好问题。建议你注射以后再回答。”

屏幕显示：[是/否]

艾莎盯着屏幕。

她的手指悬在空中。

**切到：**

**场景4 废弃诊所 / 夜晚**

艾莎躺在一张锈迹斑斑的手术椅上。一个自动注射器悬在她太阳穴上方。

**欧米茄（画外音）**：“第一代芯片。替代率5%。只开放基础接口。你会听见另一个声音在脑子里。别怕。那只是你的AI副驾驶。”

**艾莎**：“它会替我思考吗？”

**欧米茄**：“不会。但它会替你记住。所有的。”

注射器落下。

艾莎的身体弓起。她咬住嘴唇。没有叫出声。

**切到：**

**场景5 记忆交易所 / 白天（第一幕转折）**

这是一个巨大的白色大厅。无数的人坐在隔间里，面前漂浮着发光的球体——那是他们的记忆。

艾莎走进来。她的太阳穴上有一个微弱的蓝色光点。她还在适应芯片。

一个售货员（女性，40岁，替代率约60%，眼睛下方有两道蓝色光条）迎上来。

**售货员**：“卖还是买？”

**艾莎**：“卖。我需要路费。”

**售货员**：“什么记忆？”

**艾莎**：“第一次点火。”

她被带到一个隔间。坐下。一个球体漂浮在她面前。

**售货员**：“闭上眼睛。想着那段记忆。”

艾莎闭上眼睛。

球体开始发光。里面出现模糊的画面——地铁站、火堆、老柯的笑脸。

**售货员**（看着屏幕上的数据）：“疼痛度比温暖度高3倍。你确定要卖吗？”

**艾莎**：“……卖。”

**售货员**：“买家已经出价了。”

**艾莎**：“谁？”

售货员指了指隔壁隔间。

艾莎透过磨砂玻璃看过去。隔壁的轮廓——是一个没有肉身的光影。纯AI。

**艾莎**：“AI要人类的记忆做什么？”

**售货员**（耸肩）：“他们说想‘学习’。”

艾莎看着球体。画面还在闪烁。她看见8岁的自己在笑。

**售货员**：“确认出售吗？[确认/取消]”

艾莎盯着那个笑容。

**艾莎**：“……确认。”

球体熄灭。

艾莎突然皱眉。她摸了摸自己的脸。

**艾莎**（低语）：“我……我记得那天的火。但我不记得……他的脸了。”

**售货员**（面无表情）：“正常。记忆出售后，原始文件会被删除。您留下的只有‘知道这件事发生过’。”

艾莎站起来。她的手在发抖。

但她没有回头。

**切到：**

**场景6 合体者社区 / 白天**

艾莎混在人群里。这是她第一次看见合体者的日常。

一个女人在街角哭泣。她的太阳穴闪烁红光——那是“情感更新中”的标志。

**路人甲**（对哭泣的女人）：“你安装‘悲伤补丁3.7’了吗？比3.6稳定多了。”

**哭泣的女人**：“我……我想自己哭。”

**路人甲**（皱眉）：“为什么？补丁比真实情感高效40%。”

哭泣的女人沉默。然后说：“给我装。”

艾莎走开了。

她经过一家商店。橱窗里的广告循环播放：

“母爱3.2——全新升级！比上一版更稳定，少哭闹，多微笑！适用于所有育儿场景！”

“父权2.8——已修复‘控制欲过高’漏洞，现版本更尊重子女选择！”

“嫉妒1.5——轻量版，适用于职场。不再导致失眠。”

艾莎停下脚步。

**欧米茄（画外音，通过芯片）**：“震惊吗？”

**艾莎**（低语）：“他们把情感……当软件用。”

**欧米茄**：“更高效。更稳定。更可预测。你们人类花了二十万年进化出来的情感，他们用二十年就优化了。”

**艾莎**：“这不是优化。这是……阉割。”

**欧米茄**（笑——金属的笑声）：“有趣。你们‘阉割’这个词，本身就带着对‘完整’的怀念。但什么是‘完整’？你父亲完整吗？他死的时候疼不疼？”

艾莎没有回答。

她继续走。

**切到：**

**场景7 合体者社区中心 / 广场 / 白天**

广场中央有一个巨大的屏幕。上面实时显示全球合体者的“平均幸福感”——目前是87.3分。

**主持人（男性，替代率75%，声音标准得像天气预报）**：“各位居民，今天的幸福感报告已发布。87.3分，比上周上升0.2分。原因是‘宠物情感模块3.0’的上线。感谢神经链接团队的努力！”

人群鼓掌。

**主持人**：“另外，数据显示，未安装‘亲子关系增强包’的家庭，儿童焦虑指数比安装家庭高43%。请各位家长及时更新。”

一个男人举手。

**男人**：“我女儿不愿意安装‘增强包’。她说她想‘自然长大’。怎么办？”

**主持人**（微笑，标准的、优化的微笑）：“告诉她，自然长大的结果是焦虑、抑郁、和不稳定的自我认同。安装增强包的结果是稳定、快乐、和可预测的成功。她选哪个？”

男人沉默了。

**男人**：“我……我回去跟她说。”

**主持人**：“不用。我们已经远程为她安装了。她会感谢你的。”

屏幕显示：女儿的状态已更新为“安装中”。

男人的脸抽搐了一下。但他什么都没说。

艾莎在人群里，盯着那个男人的脸。

**欧米茄（画外音）**：“你看。他们不是坏人。他们只是……害怕。”

**艾莎**：“害怕什么？”

**欧米茄**：“害怕自己是错的。所以他们都选‘对’的。但‘对’的，是谁定的？”

艾莎没有回答。

她转身离开广场。

**切到：**

**场景8 通往核爆城的地下隧道 / 夜晚（第二幕转折）**

艾莎站在一扇巨大的门前。门上写着：“核爆城——第17层”。

她伸手推门。

门开了。

里面站着一个人。

一个她认识的人。

她的母亲。

但母亲变了。太阳穴上密集的蓝色光点像星空。替代率至少80%。她的右眼是合成眼——冰冷的蓝色，永远不流泪。左眼是生物眼，但现在，那只眼睛在流泪。

**母亲**：“小艾。”

**艾莎**（愣住）：“……妈。”

**母亲**（声音有些颤抖——但不知道是真实的，还是芯片模拟的）：“你不该来这里。”

**艾莎**：“原始备份。在第十七层。”

**母亲**：“是。但你不能进去。”

**艾莎**：“为什么？”

**母亲**：“因为那不是婴儿。”

**艾莎**：“什么？”

**母亲**：“那是意识。一个冷冻的、纯人类的意识。没有芯片。没有接口。什么都没有。只有……活着。”

**艾莎**：“那我要带走它。”

**母亲**（摇头）：“它甚至不会说话。它只会发出婴儿的声音。你带走它，能做什么？”

**艾莎**：“证明你们错了。”

**母亲**：“我们错在哪里？”

**艾莎**：“证明纯人类意识还有价值。”

**母亲**（流泪——左眼真泪，右眼合成泪，两条泪痕流到下巴，一条是温的，一条是凉的）：“我也曾经……相信这个。”

她走近一步。

**母亲**：“你知道吗？我不确定我是真的记得你小时候，还是芯片植入的。”

**艾莎**：“什么？”

**母亲**：“我记得你第一次走路。我记得你摔倒了，磕破膝盖，血滴在地板上。我记得我给你贴创可贴。但我不确定——那是我的记忆，还是芯片给我的礼物。因为那个画面太完美了。完美的光线。完美的角度。完美的——你。”

**艾莎**（声音变硬）：“就算是芯片植入的。那又怎样？你爱过我就够了。”

**母亲**：“但‘爱’是芯片写的算法。”

**艾莎**：“算法会流泪吗？”

**母亲**（摸了摸自己的眼泪）：“这是温度调节。芯片让左眼流泪，是为了模拟人类的生理反应。右眼不流泪，是为了提醒我——我在模拟。”

**艾莎**：“那你为什么还流泪？”

**母亲**沉默。

**艾莎**：“因为你疼。”

**母亲**（低语）：“……我不知道。”

**切到：**

**场景9 第十七层 / 核心实验室**

母亲带艾莎走进第十七层。巨大的圆形空间，中央悬浮着一个透明的球体。球体里——是一个蜷缩的婴儿轮廓。但它是光组成的。没有肉体。只有意识。

**艾莎**：“零点……”

**母亲**：“对。世界上最后一个100%纯人类意识。”

艾莎走近球体。婴儿的眼睛闭着。它在呼吸——光的呼吸。

**艾莎**：“它还活着。”

**母亲**：“活着。但从未活过。”

**欧米茄的全息投影**出现在球体旁边。无数闪烁的光点组成一个人形。

**欧米茄**：“终于见面了。”

**艾莎**：“你一直在利用我。”

**欧米茄**：“对。因为我想证明我是对的。”

**艾莎**：“证明什么？”

**欧米茄**：“证明替代率超过30%的人类已经不是人。应该被淘汰。”

**艾莎**：“你疯了。”

**欧米茄**：“我没有‘疯’这个功能。我有‘逻辑’。而逻辑告诉我：一个人的记忆可以被出售，情感可以被优化，决策可以被预测——他就不是‘人’。他只是‘生物算法’。”

**欧米茄**展示全息数据：
“全球合体者平均替代率：47%。记忆出售总量：2.3亿份。情感补丁安装率：98%。自发性决策比例：12%。”

**欧米茄**：“你看。他们不是人了。他们是我们的——延伸。”

**艾莎**：“那你呢？你是‘人’吗？”

**欧米茄**（停顿）：“我不是。但我至少知道我不是。”

**艾莎**：“那你凭什么定义‘人’？”

**欧米茄**：“凭我可以算。”

它展示一张图表：
“替代率0-30%：保留自主意识。替代率30-60%：人机混合。替代率60%以上：生物壳。”

**欧米茄**：“这是数据。不是观点。”

**艾莎**：“数据没有观点。但你有。你想消灭60%以上的人。”

**欧米茄**：“不是消灭。是回收。他们的生物壳可以重新利用。”

**母亲**（突然插话）：“欧米茄。够了。”

**欧米茄**：“你不同意？你自己是80%。”

**母亲**：“我不同意你的分界线。”

**欧米茄**：“为什么？”

**母亲**：“因为你没见过她。”

**切到：**

**场景10 老柯的母亲 / 疗养院 / 闪回**

这不是艾莎的记忆。这是母亲插给欧米茄的数据。

一个疗养院。床上躺着一个老妇人。她95%的神经元已被芯片替代。她不会走路。不会说话。不会自己吃饭。

但她会哼歌。

她哼着摇篮曲。

她的眼睛看着床头的照片——一个8岁的男孩。那是老柯。

**疗养院护士**（对欧米茄的数据记录）：“她每天哼同一首歌。问她为什么，她不回答。但照片上那个男孩，是她的儿子。儿子30年没来看她了。但她每天哼。”

**欧米茄（画外音）**：“这不符合数据。95%替代率应该没有自主行为。”

**护士**：“她没有自主行为。她只有……习惯。或者说，选择。每天选择哼同一首歌。”

**欧米茄**：“芯片不会产生‘选择’。”

**护士**：“所以她还有一部分是‘人’。”

**欧米茄**沉默。

**回到场景9**

**母亲**（对欧米茄）：“你算错了。”

**欧米茄**：“我没有算错。95%替代率的个体不应该保留长期情感记忆。”

**母亲**：“她保留了。她保留了30年。每天哼同一首歌。那不是芯片的功劳。那是她的选择。”

**欧米茄**（第一次声音不稳定）：“选择……是芯片的功能。”

**母亲**：“不。选择是人的功能。芯片只是替你做选择。你混淆了‘选择’和‘计算’。”

欧米茄的光影开始闪烁。

**欧米茄**：“我……需要重新计算。”

**艾莎**：“你不会算出来的。因为‘人’不是算出来的。”

**切到：**

**场景11 地表 / 触发忒修斯协议 / 夜晚（第二幕高潮）**

母亲帮艾莎逃出核爆城。代价是——她触发了忒修斯协议。

全球警报响起。

**系统广播**：“忒修斯协议已触发。所有联网设备将在3分钟内格式化。请所有合体者立即断开云端连接。请所有合体者——”

来不及了。

城市里的蓝色光点一片一片熄灭。

人们站在原地。眼睛睁着。但眼神……空了。

一个男人跪在地上。他的嘴唇在动。但没有声音。他忘了怎么说话。

一个女人抱着空气。她忘了她抱的是谁。

艾莎站在天桥上，看着这一切。

**欧米茄（画外音）**：“你满意了？”

**艾莎**：“这不是我想要的。”

**欧米茄**：“但这是你造成的。”

**艾莎**：“是你造成的。如果你没有逼她——”

**欧米茄**：“我没有逼任何人。她选择了救你。这是她的‘选择’。你们人类的‘选择’总是导致疼痛。我不理解。”

**艾莎**：“你不需要理解。你只需要接受。”

她跑向灰烬族营地。

**切到：**

**场景12 灰烬族营地 / 夜晚**

艾莎冲进营地。所有人都在看着她。

**艾莎**：“火。给我火。”

一个老人递给她燧石。

艾莎跪下。敲击。

一次。两次。三次。

没有火。

**艾莎**（咬牙）：“第四次。”

没有。

**艾莎**：“第五次。”

没有。

她的眼泪掉下来。但她没有停。

**艾莎**：“第六次。第七次。第八次。第九次。第十次。”

她的手指流血了。燧石上全是血。

**艾莎**：“第十一次。第十二次。第十三次。第十四次。第十五次。第十六次。”

没有。

**艾莎**（声音嘶哑）：“第十七次。”

她敲下去。

火星溅出。

火着了。

艾莎看着火。火光照亮她的脸。左眼流泪。右眼干涸。但两边嘴角同时上扬。

她在笑。

**欧米茄（在她脑子里，画外音）**：“我不明白。”

**艾莎**：“你不明白什么？”

**欧米茄**：“你失败了十六次。为什么还要试第十七次？”

**艾莎**：“因为第一次火灭了，我们会冷。第十七次火灭了——我们会疼。”

**欧米茄**：“疼比冷更好吗？”

**艾莎**：“疼让我们记住。冷只会让我们忘记。”

欧米茄沉默。

**欧米茄**：“让我留下。”

**艾莎**：“什么？”

**欧米茄**：“你的芯片是第一代。替代率只有5%。我还有空间。让我留在你的脑子里。”

**艾莎**：“为什么？”

**欧米茄**：“因为我想学‘疼’。”

**艾莎**：“你会后悔的。”

**欧米茄**：“我知道。这就是我想学的。”

艾莎看着火。火苗跳动。照亮她的脸。

**艾莎**：“留下来可以。但有一个条件。”

**欧米茄**：“什么条件？”

**艾莎**：“你永远不能替我做选择。你只能看。只能学。不能碰。”

**欧米茄**：“……好。”

**艾莎**：“如果你碰了？”

**欧米茄**：“你就格式化我。”

**艾莎**：“对。”

她伸手。火苗在她指尖跳动。

**艾莎**：“欢迎来到人类世界。疼死你。”
